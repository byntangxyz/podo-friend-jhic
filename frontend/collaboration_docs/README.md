# Collaboration Docs - PodoFriend Frontend

Direktori ini berisi dokumentasi teknis dan panduan serah terima (*handover*) proyek untuk tim pengembang yang melanjutkan pengembangan frontend PodoFriend.

## Berkas Dokumentasi:
- 📘 [FRONTEND_HANDOVER_DOCUMENTATION.md](./FRONTEND_HANDOVER_DOCUMENTATION.md): Dokumentasi lengkap mencakup arsitektur, konfigurasi lingkungan `.env`, seluruh fitur Phase 1–3, arsitektur multi-sesi, Nitro Server Streaming, integrasi Vocabulary Bank, dan panduan pengujian.
- 🎨 [MASCOT_ANIMATION_PLAN_V1.md](./MASCOT_ANIMATION_PLAN_V1.md): Rencana dan spesifikasi awal sistem animasi dinamis Podo mascot V1.
- 🚀 [MASCOT_ANIMATION_PLAN_V2.md](./MASCOT_ANIMATION_PLAN_V2.md): Dokumentasi sistem animasi maskot terpadu V2 (transisi morph halus, state machine chat & timer, aturan 2-maskot chatbot).
- 📋 [DAILY_SURVEY_AND_DASHBOARD_UI_PLAN.md](./DAILY_SURVEY_AND_DASHBOARD_UI_PLAN.md): Rencana implementasi Daily Survey horizontal dengan aset SVG resmi, rank #1 leaderboard putih, penjajaran dashboard header, dan optimasi ketinggian Pomodoro Timer.
- ⚡ [DAILY_SURVEY_STEP2_AND_TIMER_RULES_PLAN.md](./DAILY_SURVEY_STEP2_AND_TIMER_RULES_PLAN.md): Rencana implementasi Survey Step 2 (Mode Belajar Cepat/Normal/Lambat dari aset SVG), widget Preferensi Belajar dashboard, audio alarm timer habis, dan aturan wajib break setelah sesi fokus.
- 🦊 [MASCOT_SIDEBAR_AND_UI_ENHANCEMENT_PLAN.md](./MASCOT_SIDEBAR_AND_UI_ENHANCEMENT_PLAN.md): Rencana implementasi maskot animasi reaktif sidebar (pengganti `pomodoro_right_bar.svg`), pembaruan ikon api `FireStreak.svg` pada gamifikasi stats, dan standardisasi font Plus Jakarta Sans.
- ✨ [MEMORABLE_LANDING_PAGE_PLAN.md](./MEMORABLE_LANDING_PAGE_PLAN.md): Proposal arsitektur dan konsep desain Landing Page interaktif, berkesan (*memorable*), dengan Living Interactive Mascot, Bento Grid fitur modern, dan AI Simulator Playground.
